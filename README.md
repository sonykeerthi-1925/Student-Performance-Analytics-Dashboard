Student Performance Analytics Dashboard

Project Overview

This project presents a statistical analysis of student academic performance using the UCI Student Performance Dataset.

The dashboard explores academic grades, study time, and student performance patterns through data analysis and visualization.

Dataset Information

- Dataset Source: UCI Machine Learning Repository
- Total Students: 649
- Total Variables: 33

Statistical Methods

- Descriptive Statistics
- Spearman Rank Correlation
- Kruskal-Wallis Test
- Dunn's Post-hoc Test with Holm Correction

Visualizations

1. Average Final Grade
2. Average Grade by Study Time
3. Grade Comparison (G1, G2, G3)
4. Final Grade Distribution

Technologies Used

- Python
- Pandas
- Matplotlib
- HTML
- CSS
- Google Colab

Project Findings

The analysis identified a positive association between study time and final grades. Previous period grades also showed strong positive correlations with final grades.

Correlation does not imply causation.

Limitations

- The dataset contains students from two Portuguese secondary schools.
- The analysis is observational.
- Findings may not generalize to all student populations.
